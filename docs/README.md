# Slot Game Documentation

This project contains a simple slot machine game built with Phaser 3.

## Running the Game

Open `index.html` in a modern web browser. The game uses the Phaser CDN, so no additional setup is required.

## How to Play

Press the **SPIN** button to spin the reels. If all three symbols match, you win.

## Project Structure

- `index.html` - sets up the HTML page and loads Phaser and the game script.
- `game.js` - contains the game logic implemented in Phaser.
- `docs/README.md` - this documentation file.
